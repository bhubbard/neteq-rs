neteq-rs — WebRTC Adaptive Audio Jitter Buffer & Packet-Loss Concealment in Rust

neteq-rs extracts Chromium and libWebRTC's gold-standard NetEq adaptive audio jitter buffer into a standalone, memory-safe Rust crate. It dynamically absorbs network packet arrival jitter using WSOLA time-stretching and pitch-synchronous packet-loss concealment to keep real-time VoIP and AI voice calls crystal clear.

03 // CORE SUBSYSTEMS (crates/neteq-core/src/) ZERO C/C++ DEPENDENCIES

delay_manager.rs & packet_buffer.rs

Tracks sliding 100-packet inter-arrival time (IAT) histograms and RFC 3550 smoothed transit jitter ($J \leftarrow J + (|D| - J)/16$), adapting `target_delay_frames` to the 95th percentile with RFC 1982 wraparound-safe RTP ordering.

time_stretch.rs (WSOLA + MPM)

Computes Normalized Cross-Correlation (NCC) using $O(1)$ prefix-sum window energy queries and McLeod Pitch Method (MPM) subharmonic disambiguation ($60\text{–}400\text{ Hz}$), blending pitch periods via raised-cosine Hann overlap-add.

plc.rs, cng.rs & metrics.rs

Extrapolates missing frames via phase-continuous pitch templates with $0.94^f$ per-sample decay, RFC 3389 SID + ZCR/RMS Voice Activity Detection, Smooth Merge crossfading, and ITU-T G.107 E-model `MOS-LQ` scoring.
